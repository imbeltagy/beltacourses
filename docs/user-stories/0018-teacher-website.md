# US-0018 — Teacher Website

- **Phase:** Phase 2 — Teacher Platform & Monetization
- **Tasks:** T-019
- **Status:** Pending

## Story

As a teacher, I want my own website, so that my students see only my courses and my branding.

## Details

- Each teacher can get a dedicated website listing only his own courses.
- The courses still live in the main academy — the website is another window on them.
- Students log in to the teacher website with the **same account** they use on the main app.
- Only the teacher's banners are shown there; system banners are not.

## Acceptance criteria

- [ ] A teacher website resolves to exactly one teacher and lists only his courses.
- [ ] A main-app account can sign in on the teacher website.
- [ ] Only that teacher's banners are served on his website.
