# US-0023 — Academy Accounts

- **Phase:** Phase 3 — Academies
- **Tasks:** T-024, T-026
- **Status:** Pending

## Story

As an academy, I want to register on the platform and bring my teachers in, so that we operate as one
organisation instead of separate teachers.

## Details

**Sign up (T-024)** — an academy can register as its own entity, alongside teachers.

**Moderator & invitations (T-026)** — the academy has an **academy moderator** account that:

- owns an academy wallet;
- sends invitations to teachers to join the academy;
- acts on behalf of the academy in the course workflow (US-0025).

## Acceptance criteria

- [ ] An academy can sign up and gets an academy moderator account.
- [ ] The academy has its own wallet (US-0009).
- [ ] A moderator can invite a teacher, and the teacher can accept or decline.
- [ ] An accepted teacher is linked to the academy; the link can be removed.
