# US-0028 — MCQ Assignments

- **Phase:** Phase 4 — Live Courses & Assignments
- **Tasks:** T-030
- **Status:** Pending

## Story

As a student, I want graded multiple-choice assignments on lectures, so that I can check what I
understood — without being locked out if I fail.

## Details

- MCQ assignments attached to a lecture, with a grade per attempt.
- The assignment is part of the course sequence (US-0013): the student marks it complete to unlock
  what comes next, and **passing is not required** — a failing grade still lets the course continue.

## Acceptance criteria

- [ ] A teacher can attach MCQ questions with answers to a lecture.
- [ ] A student can submit answers and receive a grade.
- [ ] Grades are stored per student per assignment.
- [ ] Marking the assignment complete unlocks the next item whatever the grade.
- [ ] Course progress is never blocked by a failed or skipped assignment.
