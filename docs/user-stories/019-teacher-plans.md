A teacher picks a plan at sign-up and can change it later.

### Free

Regular flow: courses live in the academy and the system takes its fee per sale.

### Website

A website for the teacher. Courses still live in our academy and students sign in with the same account as the main app. Only the teacher's banners are shown.

### Exclusive

A website whose courses exist only there, with separate student accounts.

Plan capabilities are enforced across the API, and pricing/fees are configurable.
