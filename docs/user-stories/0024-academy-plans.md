# US-0024 — Academy Plans

- **Phase:** Phase 3 — Academies
- **Tasks:** T-025
- **Status:** Pending

## Story

As an academy, I want a plan that matches my size, so that I pay according to how many teachers I
host.

## Details

- Plans now exist for **teachers and academies**.
- Both can enable **website** and **exclusive** with extra fees.
- A teacher has no size choice; an academy must pick a size tier, each with its own price:
  - ≤ 10 teachers
  - ≤ 50 teachers
  - \> 50 teachers

## Acceptance criteria

- [ ] An academy picks a size tier at sign-up and can upgrade it.
- [ ] The number of linked teachers is enforced against the tier.
- [ ] Website and exclusive add-ons are billed on top of the tier price.
