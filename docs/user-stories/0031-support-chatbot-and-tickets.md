# US-0031 — Support Chat Bot and Tickets

- **Phase:** Phase 5 — AI
- **Tasks:** T-033
- **Status:** Pending

## Story

As a guest or a signed-in user, I want to chat with a bot about the academy, so that I get an answer
right away or a support ticket when the bot cannot help.

## Details

- Chat available to guests and to signed-in users.
- Answers questions about the academy.
- Can open a **support ticket** on the user's behalf when the question needs a human.

## Acceptance criteria

- [ ] Guests and users can start a chat session.
- [ ] The bot answers academy-related questions.
- [ ] The bot can create a support ticket carrying the conversation context.
- [ ] Tickets are visible to authorized support staff and can be resolved.
