## Users types

- Moderators \[ admin, super admin \]
- clients \[ student, teacher, academy moderator \]

## User creation

### Super admin

Created directly from database with seed file

### Admin

Only created by super admin and receive an email to login and reset password

### Student, Teacher, Academy Moderator

Regular sign up and choose one of the three roles

- Academy moderator invites already existing teachers to the acadmy or not signed users to create account and join the academy
