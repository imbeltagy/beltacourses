# US-0026 — Live Courses

- **Phase:** Phase 4 — Live Courses & Assignments
- **Tasks:** T-028
- **Status:** Pending

## Story

As a teacher or academy, I want to run a live course that students book in advance, so that I can
teach on a schedule and still keep the recordings.

## Details

- A new course type: **live**.
- The teacher/academy advertises the course with an intro, a thumbnail, a start date, a schedule and
  an end date; students **book** it.
- When the course starts, sessions are delivered live, and each live session is **recorded and stored
  in our records** per lecture.
- A student who missed a session can watch the recording afterwards.

## Acceptance criteria

- [ ] A live course can be created with intro, thumbnail, start date, schedule and end date.
- [ ] Students can book a live course, and booking is closed after the start date.
- [ ] Live sessions are recorded and attached to their lecture.
- [ ] A booked student can watch a recording of a session they missed.
