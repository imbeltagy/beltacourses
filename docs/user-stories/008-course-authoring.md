## Course

- Required: title, description, thumbnail, price.
- Optional: intro video and a markdown introduction (can embed images and links).
- A new course starts as **draft**: invisible to students and can't be purchased.

## Module

- Belongs to a course, ordered.
- Only a title and a description. Holds the lectures.

## Lecture

- Belongs to a module, ordered.
- Title, description and markdown content.
- Optional video, shown on top of the content.
- Can be flagged as a free **demo** lecture.

## Access

Only the owning teacher (or an authorized admin) can edit the course. Modules and lectures can be added, reordered and removed.
