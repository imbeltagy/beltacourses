# US-0020 — Teacher Plans

- **Phase:** Phase 2 — Teacher Platform & Monetization
- **Tasks:** T-021
- **Status:** Pending

## Story

As a teacher, I want to choose a plan when I sign up, so that I pay for exactly the reach I want.

## Details

Plans available at teacher sign-up:

1. **Free** — the regular flow: upload courses to the academy, the system takes its fee per sale.
2. **Website** — a website for the teacher (US-0018). Courses still live in our academy and students
   sign in with the same email as the main app. The website shows only the teacher's banners, not
   system banners.
3. **Exclusive** — a website whose courses exist only on the teacher website, and students hold an
   explicit account for that website (US-0019).

## Acceptance criteria

- [ ] A teacher picks a plan at sign-up, and the plan can be changed later.
- [ ] Plan capabilities (website, exclusive, fees) are enforced across the API.
- [ ] Plan pricing/fees are configurable, not hard-coded.
