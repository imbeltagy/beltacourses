# US-0015 — Banners

- **Phase:** Phase 2 — Teacher Platform & Monetization
- **Tasks:** T-016
- **Status:** Pending

## Story

As an admin, I want to publish banners on the home page, so that I can promote courses and teachers.

## Details

- A banner is an image with an optional link target: a teacher profile, a course, or nothing (image
  only).
- Banners appear in a swiper on the home page, in a controlled order.

## Acceptance criteria

- [ ] An authorized admin can create, update, reorder and delete banners.
- [ ] A banner links to a teacher profile, a course, or nothing.
- [ ] The home endpoint returns active banners in order.
