# US-0019 — Exclusive Content (Tenancy)

- **Phase:** Phase 2 — Teacher Platform & Monetization
- **Tasks:** T-020
- **Status:** Pending

## Story

As a teacher on the exclusive plan, I want my content to live only on my own website with its own
accounts, so that my audience is mine and not shared with the main academy.

## Details

- The teacher website becomes a **tenant**: its users are separate accounts, not accounts of the main
  app.
- A student of an exclusive website has an explicit account for that website only.
- Exclusive courses are not listed in the main academy catalogue.

## Acceptance criteria

- [ ] Every account, purchase and progress record is scoped to a tenant.
- [ ] A main-app account cannot access an exclusive tenant, and vice versa.
- [ ] Exclusive courses never appear in the main academy catalogue or search.
