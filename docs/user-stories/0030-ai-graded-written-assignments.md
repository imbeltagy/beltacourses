# US-0030 — AI-graded Written Assignments

- **Phase:** Phase 5 — AI
- **Tasks:** T-032
- **Status:** Pending

## Story

As a teacher, I want written assignments on my lectures graded by the AI, so that students get
feedback on open questions without me grading every submission.

## Details

- Written (free-text) assignments in addition to MCQ (US-0028).
- Grading is done by the AI, with feedback returned to the student.

## Acceptance criteria

- [ ] A teacher can attach a written assignment to a lecture.
- [ ] A student can submit an answer and receive an AI grade and feedback.
- [ ] Grades are stored per student per assignment.
- [ ] Course progress is never blocked by a written assignment.
