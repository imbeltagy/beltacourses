# US-0010 — Student Course Lists

- **Phase:** Phase 1 — MVP
- **Tasks:** T-010
- **Status:** Pending

## Story

As a student, I want a favourites list and a list of the courses I own, so that I can come back to
what interests me and reach what I paid for.

## Details

- Favourites (save list): add/remove any published course.
- Owned list: filled by a successful purchase and linked to its transaction.

## Acceptance criteria

- [ ] A student can add and remove a course from favourites, without duplicates.
- [ ] A completed purchase adds the course to the owned list.
- [ ] Course access checks read from the owned list.
